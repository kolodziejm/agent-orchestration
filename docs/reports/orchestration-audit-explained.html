Trzy milestone’y, nie osiem refaktorów

Najpierw domknij gwarancje w Pi. Dopiero później zwiększaj szerokość wsparcia.

Minimal runtime milestone · implemented

  1. Wykonywane Draft 2020-12 JSON Schema i delegation graph.
  2. Graf, cele, cykle i leaf roles są fail-closed.
  3. Pi target ceilings są zainstalowane i deterministycznie testowane.
  4. Suite deterministyczny przechodzi 170 testów; denial tests i snapshoty są w CI.

Workflow / ownership · deferred

  1. Gates i repair budget pozostają w prozie.
  2. Brak worktree owner, lease i registry.
  3. Worker nie wykonuje self-checków.
  4. Nie budujemy state/workflow control-plane w tym kroku.

Live evidence / eval · Partial

  1. Drugi lokalny canary potwierdził transcript plannera, brak nieoczekiwanych parent tools, bounds marker/cleanup i odmowę planner → validator.
  2. Nie potwierdził planner → explorer ani ukończenia plannera; overall status canary: FAIL.
  3. Live proof pozostaje Partial; canary nie uruchamia się w CI/default i nie planujemy automatycznego kolejnego płatnego runu.
  4. Model diversity i szeroki eval suite są odroczone; mechaniczny validator pozostaje ownerem acceptance.

Nie musisz pisać własnego harnessu od zera.
