Orkiestrator na max — i jedno źródło prawdy zamiast trzech literałów

Poziom „myślenia" sesji głównej był zapisany w profilu jako intencja, ale instalator Pi wstawiał do settings.json własny, twardy literał. Zmiana domyka ten rozjazd: wartość jest teraz wyprowadzana z definicji profilu, więc nie może się rozjechać z tym, co profil deklaruje.

199 testów kontraktowych OK instalacja: 2 zapisy primary: high → max 4 pliki w repo zmiana aktywna od następnego startu baseline e702fda · 14.09.2026

Dlaczego

Orkiestrator powinien być najbardziej „myślącym" elementem floty — a był jedynym, który myślał płycej niż własne dzieci.

W profilu deepseek role dziecięce miały już max (planner, reviewer, worker-complex, debugger), a sesja główna — high. Dodatkowo wartość orkiestratora nie wynikała z profilu, tylko z osobnego literału w installerze, więc każda przyszła zmiana profilu mogła zostać po cichu zignorowana.

def profile_primary_thinking(profile: str) -> str: """Return the profile's declared primary thinking level.""" import tomllib # Python 3.11+ profile_path = ROOT / "profiles" / f"{profile}.toml" with profile_path.open("rb") as handle: definition = tomllib.load(handle) thinking = definition["control_plane"]["primary"]["effort"] if not isinstance(thinking, str) or not thinking.strip(): raise SystemExit(f"Profile {profile} declares no primary thinking level") return thinking

Pułapki, które ta zmiana odsłoniła

Każda z nich może zmylić przy następnej pracy z profilami.

P2

install-pi bez flag celuje w inny profil

Wywołanie ./scripts/install-pi bez argumentów obsługuje profil domyślny, nie deepseek — i odpowiada „Pi configuration is already synchronized", mimo że profil deepseek pozostał nietknięty. Poprawne wywołanie: --profile deepseek --target ~/.pi/profiles/deepseek. Warto dopisać do README, bo komunikat jest mylący.

P2

Zmiana działa od następnego startu

Poziom myślenia jest ustalany w momencie uruchomienia sesji, więc działająca sesja zachowuje wartość z chwili startu. Efekt max widać dopiero po restarcie pi-deepseek.

P3

Render przepisał 100 plików w generated/

./scripts/render regeneruje wszystkie adaptery, więc przy okazji zmaterializował niezacommitowaną pracę nad polityką i adapterami do snapshotów. Treść pochodzi ze źródeł repo, ale stan working tree się zmienił — cofnięcie: git checkout -- generated/.

P4

Pozostałe profile nadal mają literały

Ścieżki GLM (high) i openai (medium) wciąż wpisują wartość na sztywno. Ten sam wzorzec „wyprowadź z profilu" można zastosować tam osobno.
